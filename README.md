# MiniWWS - 迷你战舰世界

在线试玩：https://tigerfan.github.io/miniWWS/

## 简介

MiniWWS 是一款基于网页的 **3D 海战模拟游戏**，还原了《战舰世界》的核心玩法。采用 Three.js 实现 3D 实时渲染，无需下载安装，打开浏览器即可体验10v10大规模海战！

## 游戏特色

### 🎮 核心玩法
- **10v10 大规模海战**：指挥友军舰队与敌军展开激烈对抗
- **三种舰种**：驱逐舰(DD)、巡洋舰(CA)、战列舰(BB)，各具特色
- **占领点机制**：控制地图上的战略要点获取胜利积分
- **胜利条件**：全歼敌军、先达到1000分、或时间结束时分数领先

### 🚢 舰种介绍

| 舰种 | 特点 | 主炮 | 鱼雷 | 机动性 |
|------|------|------|------|--------|
| 驱逐舰 | 高速灵活，鱼雷凶猛 | 较弱 | 强力(8发) | 36节 |
| 巡洋舰 | 均衡多面手 | 中等 | 中等(6发) | 30节 |
| 战列舰 | 重甲巨炮 | 强力(12发) | 较弱(4发) | 22节 |

### 🎯 操作方式

| 按键 | 功能 |
|------|------|
| W/A/S/D | 控制舰船移动 |
| 鼠标 | 瞄准炮塔 |
| 左键 | 发射主炮 |
| 右键 | 发射鱼雷 |
| 空格 | 紧急刹车 |
| R | 维修损伤 |
| 1-9, 0 | 切换控制的舰船 |

### 🗺️ 地图系统

游戏包含5张不同风格的地图：

- **海岛**：岛屿密布的热带海域，适合伏击和近战
- **北极光**：冰川环绕的寒冷海域，长距离交战
- **沉睡的巨人**：火山岛屿群，控制中央水道是关键
- **火焰群岛**：活跃的火山群岛，地形复杂多变
- **荒漠之泪**：沙漠中的绿洲海域，视野开阔

### 📊 游戏界面

- **顶部计分板**：显示双方分数、占领点数、倒计时
- **左侧面板**：友军舰队状态（点击切换控制）
- **右侧面板**：敌军舰队状态
- **底部HUD**：当前舰船的血量、武器状态、速度
- **右下角**：小地图，显示全局战场态势
- **占领点**：显示占领进度，争夺时闪烁警告

## 战术要点

1. **占领点争夺**：控制更多占领点可持续获得积分
2. **团队配合**：AI友军会自动配合，你也可以随时接管任意舰船
3. **距离控制**：战列舰保持远距离，驱逐舰利用机动近身鱼雷
4. **血量管理**：低血量时撤退维修，避免被击沉
5. **集火残血**：优先击杀低血量敌人获取分数

## 技术特点

- **Three.js 3D 渲染**：自定义海洋着色器、3D 舰船模型、动态光影
- **双层渲染架构**：3D 场景 + 2D Canvas HUD 叠加层
- 纯前端实现，无需后端服务器
- 响应式设计，支持各种屏幕尺寸
- 支持键盘+鼠标操作

## 本地运行

```bash
# 克隆仓库
git clone https://github.com/tigerfan/miniWWS.git

# 进入目录
cd miniWWS

# 使用任意静态服务器运行
# Python 3
python -m http.server 8080

# Node.js
npx serve .

# 然后打开浏览器访问 http://localhost:8080
```

## 浏览器兼容性

- Chrome/Edge（推荐）
- Firefox
- Safari

需要支持 ES6+、Canvas 和 WebGL 的现代浏览器。
